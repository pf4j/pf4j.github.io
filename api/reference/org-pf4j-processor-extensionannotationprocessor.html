org.pf4j.processor

ExtensionAnnotationProcessor

Processes Extension annotations and generates an ExtensionStorage.

ExtensionAnnotationProcessor

Extends: AbstractProcessor

Processes [Extension](org-pf4j-Extension.html#extension) annotations and generates an [ExtensionStorage](org-pf4j-processor-ExtensionStorage.html#extensionstorage).

You can specify the concrete [ExtensionStorage](org-pf4j-processor-ExtensionStorage.html#extensionstorage) via processor's environment options ([ProcessingEnvironment#getOptions()]({#ref #})) or system property. In both variants the option/property name is pf4j.storageClassName.
