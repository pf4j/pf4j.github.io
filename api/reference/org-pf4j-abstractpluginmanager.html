org.pf4j

AbstractPluginManager

This class implements the boilerplate plugin code that any PluginManager implementation would have to support.

AbstractPluginManager

Extends: org.pf4j.PluginManager Subclassed by: org.pf4j.DefaultPluginManager

This class implements the boilerplate plugin code that any [PluginManager](org-pf4j-PluginManager.html#pluginmanager-5) implementation would have to support.

It helps cut the noise out of the subclass that handles plugin management.

This class is not thread-safe.

Author: Decebal Suiu

startDependencies

boolean startDependencies(PluginWrapper pluginWrapper)

Defined in pf4j/src/main/java/org/pf4j/AbstractPluginManager.java:463

Starts all dependencies of a plugin and validates that required dependencies started successfully.

This method is called before [doStartPlugin(PluginWrapper)]({#ref #}) to ensure all dependencies are in a valid state before starting the dependent plugin.

Behavior for required dependencies:

  • If a required dependency fails to start (state is not [PluginState#STARTED]({#ref #})), the dependent plugin will NOT be started

  • The dependent plugin state is set to [PluginState#FAILED]({#ref #})

  • A [PluginRuntimeException](org-pf4j-PluginRuntimeException.html#pluginruntimeexception) is set as the failure cause

  • An error is logged indicating which dependency failed

  • A state change event is fired

Behavior for optional dependencies:

  • If an optional dependency is not loaded, it is skipped (no attempt to start)

  • If an optional dependency is loaded but fails to start, a warning is logged

  • The dependent plugin will still be started (allows degraded mode/reduced functionality)

  • It is the plugin's responsibility to handle missing optional dependencies gracefully

Returns

true if all required dependencies started successfully and the plugin can proceed to start; false if a required dependency failed to start (plugin state is set to FAILED)

Parameters

ParameterTypeDescription
pluginWrapper[PluginWrapper](org-pf4j-PluginWrapper.html#pluginwrapper)the plugin whose dependencies should be started
